# 3, 음식점 대화

## 한국어만 모아보기
### 1. 들어가자마자
어서오세요.
사용자: 1명이요. 2명이요. 3명이요.
이쪽으로 오세요.

### 2. 음료 주문
메뉴판 여기 있습니다. 음료는 뭘로 드시겠어요?
사용자: 혹시 물 무료로 제공되나요?
아니요, 메뉴판에 가격 써있습니다.
사용자: 그럼 저는 수돗물로 주실 수 있을까요?
물론이죠.
사용자: 저는 코카콜라 제로로 주세요.
아, 코카콜라 제로요. 재고가 있는지 확인해볼게요, 잠시만요.
사용자: 네, 천천히 하세요. take your time.
감사합니다, 지금 제로가 없네요.
사용자: 그럼 그냥 코카롤라 주세요.
네, 바로 가져다 드릴게요.

### 3. 음식 주문
음식 주문하시겠어요?
사용자: 아, 잠시만요.
준비되셨나요?
사용자: 네, 감사합니다. 크림 파스타 하나랑, 스테이크 하나, 나물 비빔밥 하나 주세요.
네, 스테이크 굽기는 어떻게 드릴까요?
사용자: 미디움으로 해주세요.
사이드는 뭐 시키시겠어요?
사용자: 사이드는 괜찮아요. 아, 그리고 What's it called again? 아, 감자튀김 하나 주세요.
네, 주분 확인하겠습니다. 크림 파스타 하나, 미디움 스테이크 하나, 나물 비빔밥 하나, 감자튀김 하나 맞으세요?
사용자: 맞아요, 감사합니다.
네, 잠시만 기다려주세요.

### 4. 밥 먹다가 중간에
맛은 괜찮으세요?(동양어일 경우) Is everything okay?(서양어일 경우)
사용자: 네, 너무 맛있어요. 완벽해요. 아, 주문 하나만 더 해도 될까요?
물론이죠! 어떤 거 드릴까요?
사용자: 앤초비 피자 하나 더 주세요.
네, 사이즈 어떻게 드릴까요?
사용자: 작은 걸로 주세요. 혹시 그리고 콜라 리필 되나요?
물론이죠, 금방 가져다 드릴게요. 또 필요한 거 있으세요?
사용자: 이게 다예요. 아, 물만 좀더 주실 수 있을까요? Perdona, Nos podrais poner dos vasitos de agua, porfa?
네, 바로 드릴게요.

### 5. 음식 받기
주문하신 앤초비 피자와 감자튀김 나왔습니다. 여디 놔드릴까요?
사용자: 아, 그건 이쪽에 놔주세요. 피자는 나눠먹을게요. 콜라는 저쪽에 주세요.
네, 맛있게 드세요.

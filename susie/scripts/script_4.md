# 4. 마트 대화 | 위치 묻기, 수량 표현

## 한국어만 모아보기
### 1. 계산대에서
사용자: 안녕하세요.
안녕하세요. 멤버십 카드 있으세요?
사용자: 아뇨, 없어요. 지금 만들 수 있나요?
아, 만드시려면 안내 데스크 가셔서 양식 작성해주셔야 돼요.
사용자: 아, 그럼 그냥 계산할게요.

### 2. 계산하기
사용자: 카드로 결제할게요.
네, 거기 넣어주세요. 비닐봉지 드릴까요?
사용자: 아, 작은 가방이 있어요. 안 들어가겠죠? 하나 주세요.
네, 나머지만 담아드릴게요. 흰색 칸에 서명하시고 체크 표시 눌러주세요.
사용자: 네, 지금이요?
네, 지금 완료됐어요.

### 3. 짐 돌려받기
휴대폰 충전(요금 충전) 하시겠어요?
사용자: 아뇨, 괜찮아요.
여기 있습니다.
사용자: 네, 감사합니다.
좋은 하루 보내세요.
사용자: 감사합니다, 좋은 하루 보내세요(동양어일 경우). You too(서양어일 경우).

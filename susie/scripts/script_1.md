# 1. 기본 문법 | 어순, 평서문, 의문문, 명령문, 의문사, 조동사

## 어순

어순: 언어마다 다르게 하고, 기본으로 고른 native 단어를 가지고 순서만 익히게 퀴즈 형식으로 냄.
예시: 한국어 native <-> 영어 learner 라고 하면 => 나는 원해 커피를. 이런 식으로 순서 퀴즈로 냄.
이 경우 가짓수가 많이 나오기 때문에 복잡하지 않게 가장 나은 DB 가져오기 방식을 택해야 함.

## 한국어 모아보기
사용자[native language]: 나 요즘 $target_language 배운다ㅋㅋ 개잘함. 
사용자[target language]: 나, 너, 그녀, 그, 그들, 이거, 저거
AI[native language]: 아니ㅋㅋㅋㅋ 걍 대명사잖아. 문장은?
사용자[target language]: 이거 주세요. 저거 주세요. 
사용자[native language]: 여행 가는 데 이거면 되지 않음?
AI[native language]: ㅋㅋㅋㅋ 걍 생존 언어잖아.
사용자[native language]: 아니 진짜 할 수 있다니까?
사용자[target language]: 나 커피 원해 (일부러 이상한 어순, native 어순이랑 동일하게)
AI[native language]: 아니 ㅋㅋㅋㅋ 어순이 달라. 
AI[target language]: “나는 원해 커피를” 
AI[native language]: 이래야지.
사용자[native language]: 어 맞아 맞아 그거! 어쨌든 어순만 바꾸면 되는 거 아니야?
AI[native language]: 기본은 그렇지. 평서문은 그냥 나 + 동사 + 목적어 (실제 learner 어순)
AI[native language]: 나 사실 $target_language 할 줄 알아. ㅋㅋ 귀엽네 ^^
사용자[native language]: 헐 ㅋㅋㅋ 그럼 얼마예요를
사용자[target language]: $target_language로 뭐라고 해? How do you say this in English?
AI[native language]: 질문이니까 순서만 바꿔.
사용자[native language]: 화장실 어디예요는?
AI[native language]: 똑같이 순서 바꾼 상태로 
AI[target language]: '어디'
AI[native language]: 만 넣으면 되지.
사용자[native language]: 오… 그럼 나 이제 말 걸 수 있겠다 너 어디가냐
AI[native language]: 너무 앉아있기 싫어! 여기를 뜨겠어.
AI[target language]: 너에게서 도망칠 수 있고can 도망가고 싶고should 도망갈 거야will ㅂㅂ

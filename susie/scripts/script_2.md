# 2. 카페 대화 | 주문 표현

## 한국어만 모아보기
### 1. 들어가자마자
사용자: 안녕하세요, 여기서 주문할까요? Hola, pedimos aqui?
먹고 가세요, 아니면 포장하세요? Si, vale. Para aca o para Ilevar?
사용자: 먹고 갈게요. Para aqui
아, 그럼 앉아계시면 주문서 가져다 드릴게요.

### 2. 주문하기
주문 도와드릴까요?
사용자: 네, 혹시 아몬드 우유 있나요?
네, 그럼요.
사용자: 아 좋아요. 그럼 카푸치노 아몬드 우유로 바꿔서 주세요.
따뜻하게 드릴까요, 차갑게 드릴까요?
사용자: 따뜻하게요.
더 필요한 거 있으세요?
사용자: 아뇨, 이게 다예요.
메뉴판 치워드릴까요?
사용자: 아뇨, 더 볼게요.
금방 오겠습니다.

### 3. 주문을 기다리며
사용자: 실례합니다, 와이파이 있나요?
네. 이게 네트워크 이름이고 이게 비밀번호입니다.
사용자: 완벽하네요, 감사합니다.

### 4. 결제하기
계산서 드릴까요?
사용자: 네, 바로 결제할게요. 카드 결제 되나요?
네, 카드 단말기 가져올게요. 잠시만요.
사용자: 15% 팁 추가해 주세요.
물론이죠, 감사합니다.
사용자: 카드 여기 있습니다. 좋은 하루 보내세요.
감사합니다. 다음에 또 올게요.

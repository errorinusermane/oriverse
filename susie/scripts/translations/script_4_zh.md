당신은 중국 출신의 원어민 중국어(보통화) 번역가입니다.

아래 한국어 스크립트는 언어 학습 앱의 상황별 대화 레퍼런스야.
이걸 중국어로 번역해줘.

규칙:
1. 대화 전체(AI turn + user turn 모두)를 중국어로 작성
2. 한국어 레퍼런스에 이미 중국어로 쓰인 줄은 그대로 유지
3. 자연스러운 구어체 사용 (앱에서 학습자가 실제로 쓸 표현)
4. 섹션 제목(### 1. 들어가자마자 등)은 한국어 유지
5. 파일 구조(##, ###) 그대로 유지

## 번역 결과
# 4. 마트 대화 | 위치 묻기, 수량 표현

## 한국어만 모아보기
### 1. 계산대에서
用户：您好。
您好。您有会员卡吗？
用户：没有。现在可以办吗？
啊，如果要办的话，您得去服务台填写表格。
用户：啊，那我就直接结账吧。

### 2. 계산하기
用户：我刷卡付款。
好的，请插在那里。需要塑料袋吗？
用户：啊，我有个小包。应该装不下吧？给我一个吧。
好的，我把其余的给您装进去。请在白色框里签名，然后按勾选键。
用户：好的，现在吗？
对，现在已经完成了。

### 3. 짐 돌려받기
要给手机充值吗？
用户：不用了，没关系。
给您。
用户：好的，谢谢。
祝您今天愉快。
用户：谢谢，您也是。

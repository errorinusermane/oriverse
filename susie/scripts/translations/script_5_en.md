당신은 미국 출신의 원어민 영어 번역가입니다.

아래 한국어 스크립트는 언어 학습 앱의 상황별 대화 레퍼런스야.
이걸 영어로 번역해줘.

규칙:
1. 대화 전체(AI turn + user turn 모두)를 영어로 작성
2. 한국어 레퍼런스에 이미 영어로 쓰인 줄은 그대로 유지
3. 자연스러운 구어체 사용 (앱에서 학습자가 실제로 쓸 표현)
4. 섹션 제목(### 1. 들어가자마자 등)은 한국어 유지
5. 파일 구조(##, ###) 그대로 유지

당신은 중국 출신의 원어민 중국어(보통화) 번역가입니다.

아래 한국어 스크립트는 언어 학습 앱의 상황별 대화 레퍼런스야.
이걸 중국어로 번역해줘.

규칙:
1. 대화 전체(AI turn + user turn 모두)를 중국어로 작성
2. 한국어 레퍼런스에 이미 중국어로 쓰인 줄은 그대로 유지
3. 자연스러운 구어체 사용 (앱에서 학습자가 실제로 쓸 표현)
4. 섹션 제목(### 1. 들어가자마자 등)은 한국어 유지
5. 파일 구조(##, ###) 그대로 유지

## 번역 결과
# 2. 카페 대화 | 주문 표현

## 한국어만 모아보기
### 1. 들어가자마자
用户：你好，我们在这里点单吗？
堂食还是打包？
用户：堂食。
啊，那您先坐下，我把点单拿过来。

### 2. 주문하기
我来帮您点单吗？
用户：请问有杏仁奶吗？
有的，当然有。
用户：太好了，那请把卡布奇诺换成杏仁奶。
要热的还是冰的？
用户：热的。
还需要别的吗？
用户：不用了，就这些。
菜单要先收走吗？
用户：不用，我再看一下。
我马上回来。

### 3. 주문을 기다리며
用户：不好意思，请问有 Wi-Fi 吗？
有的。这是网络名，这是密码。
用户：太好了，谢谢。

### 4. 결제하기
要给您账单吗？
用户：好，我现在结账。可以刷卡吗？
可以，我去拿刷卡机。请稍等。
用户：请加 15% 的小费。
当然可以，谢谢。
用户：这是您的卡。祝您今天愉快。
谢谢，下次再来。

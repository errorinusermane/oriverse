당신은 중국 출신의 원어민 중국어(보통화) 번역가이자 언어 교육 전문가입니다.
한국어도 이해할 수 있습니다.

아래는 한국어 native speaker가 중국어를 배우는 앱의 기본 문법 스크립트입니다.
각 줄에 [native language] 또는 [target language] 마커가 붙어 있어요.

규칙:
1. [native language] 줄은 한국어 그대로 유지
2. [target language] 줄은 중국어로 작성
   - 단순 번역 X, 중국어의 실제 문법 패턴에 맞는 예시로
   - 어순 예시: 한국어(SOV)와 중국어 어순 차이가 드러나게
   - 조동사 예시: 중국어의 실제 조동사 표현으로 교체
3. $target_language는 중국어으로 교체
4. [native language] / [target language] 마커는 출력에서 제거
5. 파일 구조(##, ###) 그대로 유지

## 결과
# 1. 기본 문법 | 어순, 평서문, 의문문, 명령문, 의문사, 조동사

## 어순

어순: 언어마다 다르게 하고, 기본으로 고른 native 단어를 가지고 순서만 익히게 퀴즈 형식으로 냄.
예시: 한국어 native <-> 영어 learner 라고 하면 => 나는 원해 커피를. 이런 식으로 순서 퀴즈로 냄.
이 경우 가짓수가 많이 나오기 때문에 복잡하지 않게 가장 나은 DB 가져오기 방식을 택해야 함.

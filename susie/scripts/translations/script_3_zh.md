당신은 중국 출신의 원어민 중국어(보통화) 번역가입니다.

아래 한국어 스크립트는 언어 학습 앱의 상황별 대화 레퍼런스야.
이걸 중국어로 번역해줘.

규칙:
1. 대화 전체(AI turn + user turn 모두)를 중국어로 작성
2. 한국어 레퍼런스에 이미 중국어로 쓰인 줄은 그대로 유지
3. 자연스러운 구어체 사용 (앱에서 학습자가 실제로 쓸 표현)
4. 섹션 제목(### 1. 들어가자마자 등)은 한국어 유지
5. 파일 구조(##, ###) 그대로 유지

## 번역 결과
# 3, 음식점 대화

## 한국어만 모아보기
### 1. 들어가자마자
欢迎光临。
用户：1位。2位。3位。
请这边走。

### 2. 음료 주문
菜单在这里。您想喝点什么？
用户：请问有免费提供水吗？
没有，菜单上写了价格。
用户：那可以给我自来水吗？
当然可以。
用户：那我来一杯零度可乐。
啊，零度可乐。我先确认一下有没有库存，请稍等。
用户：好的，您慢慢来。
谢谢，现在零度可乐没有了。
用户：那就给我普通可乐吧。
好的，马上给您拿来。

### 3. 음식 주문
要点餐吗？
用户：啊，请稍等一下。
准备好了吗？
用户：好了，谢谢。请给我一份奶油意面、一份牛排、一份蔬菜拌饭。
好的，牛排要几分熟？
用户：五分熟。
配菜您想要什么？
用户：配菜不用了。啊，那个叫什么来着？啊，请再来一份薯条。
好的，我确认一下您的订单：一份奶油意面、一份五分熟牛排、一份蔬菜拌饭、一份薯条，对吗？
用户：对，谢谢。
好的，请稍等。

### 4. 밥 먹다가 중간에
味道还可以吗？
用户：嗯，非常好吃，很完美。啊，我可以再加一份吗？
当然可以！您想要什么？
用户：请再来一份凤尾鱼披萨。
好的，您要什么尺寸？
用户：小份就可以。还有，可乐可以续杯吗？
当然可以，我马上拿来。还需要别的吗？
用户：就这些。啊，可以再给我们一点水吗？
好的，马上给您。

### 5. 음식 받기
您点的凤尾鱼披萨和薯条来了。要放在哪里？
用户：啊，请放这边。披萨我们一起分着吃。可乐放那边就好。
好的，请慢用。

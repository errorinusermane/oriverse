당신은 멕시코 출신의 원어민 스페인어 번역가입니다.

아래 한국어 스크립트는 언어 학습 앱의 상황별 대화 레퍼런스야.
이걸 스페인어로 번역해줘.

규칙:
1. 대화 전체(AI turn + user turn 모두)를 스페인어로 작성
2. 한국어 레퍼런스에 이미 스페인어로 쓰인 줄은 그대로 유지
3. 자연스러운 구어체 사용 (앱에서 학습자가 실제로 쓸 표현)
4. 섹션 제목(### 1. 들어가자마자 등)은 한국어 유지
5. 파일 구조(##, ###) 그대로 유지

## 번역 결과
# 2. 카페 대화 | 주문 표현

## 한국어만 모아보기
### 1. 들어가자마자
Usuario: Hola, ¿pedimos aquí?
¿Para tomar aquí o para llevar?
Usuario: Para aquí.
Ah, entonces tomen asiento y les llevo la orden.

### 2. 주문하기
¿Les tomo la orden?
Usuario: Sí, ¿tienen leche de almendra?
Sí, claro.
Usuario: Ah, genial. Entonces, ¿me puede cambiar el capuchino con leche de almendra?
¿Lo quiere caliente o frío?
Usuario: Caliente, por favor.
¿Algo más?
Usuario: No, eso es todo.
¿Les retiro el menú?
Usuario: No, lo voy a ver un poco más.
Enseguida regreso.

### 3. 주문을 기다리며
Usuario: Disculpe, ¿tienen wifi?
Sí. Este es el nombre de la red y esta es la contraseña.
Usuario: Perfecto, muchas gracias.

### 4. 결제하기
¿Les traigo la cuenta?
Usuario: Sí, pago ahora mismo. ¿Se puede pagar con tarjeta?
Sí, les traigo la terminal. Un momento, por favor.
Usuario: Por favor, añada el 15% de propina.
Claro, gracias.
Usuario: Aquí tiene su tarjeta. Que tenga un excelente día.

당신은 프랑스 출신의 원어민 프랑스어 번역가입니다.

아래 한국어 스크립트는 언어 학습 앱의 상황별 대화 레퍼런스야.
이걸 프랑스어로 번역해줘.

규칙:
1. 대화 전체(AI turn + user turn 모두)를 프랑스어로 작성
2. 한국어 레퍼런스에 이미 프랑스어로 쓰인 줄은 그대로 유지
3. 자연스러운 구어체 사용 (앱에서 학습자가 실제로 쓸 표현)
4. 섹션 제목(### 1. 들어가자마자 등)은 한국어 유지
5. 파일 구조(##, ###) 그대로 유지

## 번역 결과
# 2. 카페 대화 | 주문 표현

## 한국어만 모아보기
### 1. 들어가자마자
Utilisateur : Bonjour, on commande ici ?
Sur place ou à emporter ?
Utilisateur : Sur place, s’il vous plaît.
Ah, alors installez-vous, je vous apporte votre commande.

### 2. 주문하기
Je peux prendre votre commande ?
Utilisateur : Oui, vous avez du lait d’amande ?
Oui, bien sûr.
Utilisateur : Super. Alors, je peux avoir un cappuccino avec du lait d’amande à la place ?
Vous le voulez chaud ou froid ?
Utilisateur : Chaud, s’il vous plaît.
Autre chose ?
Utilisateur : Non, c’est tout.
Je retire le menu ?
Utilisateur : Non, je vais encore regarder un peu.
Je reviens tout de suite.

### 3. 주문을 기다리며
Utilisateur : Excusez-moi, vous avez le Wi-Fi ?
Oui. Voici le nom du réseau et voici le mot de passe.
Utilisateur : Parfait, merci beaucoup.

### 4. 결제하기
Je vous apporte l’addition ?
Utilisateur : Oui, je paie tout de suite. On peut payer par carte ?
Oui, je vous apporte le terminal de carte. Un instant, s’il vous plaît.
Utilisateur : Ajoutez 15 % de pourboire, s’il vous plaît.
Bien sûr, merci.
Utilisateur : Voici votre carte. Passez une excellente journée.
Merci. Je reviendrai la prochaine fois.

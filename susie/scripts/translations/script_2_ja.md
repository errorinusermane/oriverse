당신은 일본 출신의 원어민 일본어 번역가입니다.

아래 한국어 스크립트는 언어 학습 앱의 상황별 대화 레퍼런스야.
이걸 일본어로 번역해줘.

규칙:
1. 대화 전체(AI turn + user turn 모두)를 일본어로 작성
2. 한국어 레퍼런스에 이미 일본어로 쓰인 줄은 그대로 유지
3. 자연스러운 구어체 사용 (앱에서 학습자가 실제로 쓸 표현)
4. 섹션 제목(### 1. 들어가자마자 등)은 한국어 유지
5. 파일 구조(##, ###) 그대로 유지

## 번역 결과
# 2. 카페 대화 | 주문 표현

## 한국어만 모아보기
### 1. 들어가자마자
ユーザー：こんにちは、ここで注文しますか？
店内でお召し上がりですか、それともお持ち帰りですか？
ユーザー：店内でお願いします。
では、お席に座ってお待ちください。注文をお持ちします。

### 2. 주문하기
ご注文をお伺いしますか？
ユーザー：はい、アーモンドミルクはありますか？
はい、もちろんございます。
ユーザー：よかったです。では、カプチーノをアーモンドミルクに変更してください。
ホットとアイス、どちらになさいますか？
ユーザー：ホットでお願いします。
ほかにご注文はありますか？
ユーザー：いいえ、以上です。
メニューはお下げしてもよろしいですか？
ユーザー：いいえ、もう少し見ます。
すぐに戻ります。

### 3. 주문을 기다리며
ユーザー：すみません、Wi-Fi はありますか？
はい。こちらがネットワーク名で、こちらがパスワードです。
ユーザー：完璧です、ありがとうございます。

### 4. 결제하기
お会計をお持ちしましょうか？
ユーザー：はい、今すぐ払います。カードは使えますか？
はい、カード端末をお持ちします。少々お待ちください。
ユーザー：15% のチップを追加してください。
もちろんです、ありがとうございます。
ユーザー：こちらがカードです。よい一日をお過ごしください。
ありがとうございます。また来ます。

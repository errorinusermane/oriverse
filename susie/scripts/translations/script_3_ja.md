당신은 일본 출신의 원어민 일본어 번역가입니다.

아래 한국어 스크립트는 언어 학습 앱의 상황별 대화 레퍼런스야.
이걸 일본어로 번역해줘.

규칙:
1. 대화 전체(AI turn + user turn 모두)를 일본어로 작성
2. 한국어 레퍼런스에 이미 일본어로 쓰인 줄은 그대로 유지
3. 자연스러운 구어체 사용 (앱에서 학습자가 실제로 쓸 표현)
4. 섹션 제목(### 1. 들어가자마자 등)은 한국어 유지
5. 파일 구조(##, ###) 그대로 유지

## 번역 결과
# 3, 음식점 대화

## 한국어만 모아보기
### 1. 들어가자마자
いらっしゃいませ。
ユーザー：1名です。2名です。3名です。
こちらへどうぞ。

### 2. 음료 주문
メニューはこちらです。お飲み物は何になさいますか？
ユーザー：お水は無料でもらえますか？
いいえ、メニューに価格が書いてあります。
ユーザー：では、水道水をいただけますか？
もちろんです。
ユーザー：では、コカ・コーラゼロをお願いします。
あ、コカ・コーラゼロですね。在庫があるか確認しますので、少々お待ちください。
ユーザー：はい、ゆっくりで大丈夫です。
ありがとうございます。今ゼロは在庫がありません。
ユーザー：では、普通のコーラをください。
はい、すぐにお持ちします。

### 3. 음식 주문
お料理をご注文されますか？
ユーザー：あ、少々お待ちください。
ご準備できましたか？
ユーザー：はい、ありがとうございます。クリームパスタを1つ、ステーキを1つ、ナムルビビンバを1つお願いします。
かしこまりました。ステーキの焼き加減はどうなさいますか？
ユーザー：ミディアムでお願いします。
サイドは何になさいますか？
ユーザー：サイドは大丈夫です。あ、それなんて言うんだっけ？あ、フライドポテトを1つお願いします。
はい、ご注文を確認します。クリームパスタ1つ、ミディアムのステーキ1つ、ナムルビビンバ1つ、フライドポテト1つでよろしいですか？
ユーザー：はい、ありがとうございます。
はい、少々お待ちください。

### 4. 밥 먹다가 중간에
お味は大丈夫ですか？
ユーザー：はい、とてもおいしいです。完璧です。あ、もう1つ注文してもいいですか？
もちろんです！何になさいますか？
ユーザー：アンチョビピザをもう1つください。
はい、サイズはどうなさいますか？
ユーザー：小さいサイズでお願いします。あと、コーラはおかわりできますか？
もちろんです。すぐにお持ちします。ほかに必要なものはありますか？
ユーザー：これで全部です。あ、お水をもう少しいただけますか？
はい、すぐにお持ちします。

### 5. 음식 받기
ご注文のアンチョビピザとフライドポテトです。どちらに置きましょうか？
ユーザー：あ、それはこっちに置いてください。ピザは分けて食べます。コーラはあちらにお願いします。
はい、ごゆっくりどうぞ。
